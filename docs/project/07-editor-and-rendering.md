# Editor and Rendering

The transcription editor is the centerpiece of IDTAP -- an interactive workspace for creating, editing, and analyzing musical transcriptions overlaid on spectrogram visualizations. This document covers the rendering architecture, interaction system, and the full feature inventory.

---

## Component Hierarchy

```
EditorComponent (2992 lines) -- orchestrator, owns Piece model, manages persistence
└── Renderer (1177 lines) -- spatial layout, D3 scales, zoom, mode selectors
    ├── SpectrogramLayer -- canvas-based spectrogram tiles (see spectrogram doc)
    ├── MelographLayer -- SVG pitch contour overlay
    └── TranscriptionLayer (8056 lines) -- all D3 trajectory rendering and interaction
TrajSelectPanel (1242 lines) -- property inspector for selected elements
AssemblageEditor -- assemblage/strand management panel
EditorAudioPlayer -- audio playback controls
SpectrogramControls -- colormap, intensity, frequency range

```

## Coordinate System

Two D3 linear scales define the mapping from musical space to pixel space:

- **xScale**: Time (seconds) → pixel position. Domain `[0, durTot]`, range `[0, scaledWidth]`. The `scaledWidth` can be many times wider than the viewport for long recordings.

- **yScale**: Log-frequency → pixel position. Domain `[logMax, logMin]` (inverted so higher pitches appear higher). Centered on `log2(raga.fundamental)` with configurable octave offsets above and below.

Both scales are created in `Renderer.onMounted` and updated in watchers on zoom factors and octave offsets.

---

## Layer Compositing

Visual layers are stacked with CSS absolute positioning (bottom to top):

1. **Background layer**: Plain div with configurable color
2. **Spectrogram layer**: Multi-canvas tiled rendering (see [Spectrogram System](05-spectrogram-system.md))
3. **Melograph layer**: SVG path showing pitch tracking contour
4. **Transcription layer**: SVG with all interactive musical elements

All layers share dimensions and scroll together via a native-overflow `scrollingContainer`. The X-axis and Y-axis containers use CSS `sticky` positioning with synchronized scroll via a throttled (16ms) handler.

---

## Trajectory Rendering (D3 SVG)

Each trajectory is rendered as a pair of SVG paths:

1. **Visible path**: `d3.line` with `d3.curveMonotoneX` interpolation, colored by instrument, 3px stroke (2px for second-string)
2. **Shadow path**: Invisible (opacity 0), 10px stroke width -- serves as the mouse interaction target (makes thin curves easy to click)

Trajectory data is generated by `makeTrajData()`, which evaluates `traj.compute(x, true)` at evenly spaced time points (~10ms intervals), producing `{x: time, y: logFreq}` pairs mapped through `xScale` and `yScale`.

### Polyphonic String Differentiation
Second-string trajectories (from `trajectoryGrid[1]`) are rendered with:
- 30% darkened color via `adjustColorForSecondString()`
- Thinner 2px stroke width
- Both strings are always visible simultaneously

### Articulation Symbols
- **Plucks** (sitar): Rotated triangle symbols (`d3.symbolTriangle`)
- **Dampeners**: Bracket-like SVG paths
- **Krintin**: Arrow paths with `marker-end`
- **Consonants** (vocal): Diamond symbols (`d3.symbolDiamond`)

All symbols have invisible shadow counterparts for hit detection.

## Chunked Lazy Loading (Bidirectional)

TranscriptionLayer uses `IntersectionObserver`-based chunking to avoid rendering hours-long transcriptions at once:

- Time axis divided into chunks whose duration equals viewport width in time
- An `emptyOverlay` div contains one child per chunk, each observed by `IntersectionObserver`
- **Enter viewport**: `manuallyLoadChunk()` renders all trajectories, sargam labels, phrase divisions, chikaris, bols, vowels, consonants, and meters for that time range
- **Leave viewport**: Chunks beyond ±10 of current position are unloaded asynchronously (2 per animation frame) via `d3.selectAll('.uId...').remove()`
- **Cooldown**: 1000ms `RELOAD_COOLDOWN_MS` prevents thrashing
- **Preloading**: 2 chunks ahead and 2 behind, processed at 1 chunk per animation frame

## The Drag Dot System

When a single trajectory is selected, interactive control points appear:

- Purple circles (4px radius) at each time boundary in the trajectory's `durArray`
- Selected dot highlighted in magenta (`#d602d6`)
- D3 drag behavior with **smoothed animation**: target follows cursor, displayed position interpolates toward target at 20% per frame
- Frame-rate limited: updates every other `requestAnimationFrame` for performance

### Drag Constraints
- Phrase boundary dots are locked (cannot be moved)
- Interior dots constrained between neighbors
- Minimum trajectory duration: 0.01s
- Polyphonic-aware: uses `findPreviousTrajectoryOnSameString` and `findNextTrajectoryOnSameString` for neighbor lookup

### Drag Dot Context Menu
- **Quantize to Sargam**: Snap pitch to nearest raga pitch
- **Quantize to Meter**: Snap time to nearest meter pulse

### Keyboard Navigation
- Arrow keys: Nudge selected drag dot (left/right for time, up/down for pitch)
- Shift+Left/Right: Select adjacent drag dots
- Tab/Shift+Tab: Select next/previous trajectory or phrase

## Sargam Label Rendering

SVG text elements showing pitch names at trajectory positions, with four simultaneous representations (only one visible at a time, toggled by opacity):

- **Sargam**: Sa, Re, Ga, Ma, Pa, Dha, Ni (with case for raised/lowered)
- **Solfege**: Do, Re, Mi, Fa, Sol, La, Ti
- **Pitch class**: Numerical
- **Western**: C, D, E, F, G, A, B

Phoneme labels for vocal tracks similarly support IPA, Devanagari, and Latin representations.

---

## Phrase Division Rendering

Vertical lines spanning the full Y-axis:
- **Section divisions**: 4px wide
- **Phrase divisions**: 2px wide
- Each has an invisible 8px shadow line for click detection
- Arrow keys nudge selected division left/right by one trajectory boundary
- Nudging preserves section metadata and categorization
- For polyphonic instruments, repartitions second-string trajectories across the moved boundary

---

## Playhead Animation

Three animation modes:

| Mode | Behavior |
|------|----------|
| **Animated** | `requestAnimationFrame` with exponential smoothing (0.7 factor). Handles loop wrapping. |
| **Block** | Updates once per second. Playhead widened to 1-second visual width at 50% opacity. |
| **DottedLine** | Creates vertical dashed lines every 0.5s that fade out over 500ms. Max 20 lines maintained. |

Auto-scrolling: When the playhead moves past 85% of the viewport width, the container scrolls to keep it visible.

**Trajectory highlighting**: When enabled, the currently-playing trajectory is colored with the selection color via `piece.trajFromTime()`.

---

## Zoom and Scroll

- **Horizontal zoom**: Adjusts `scaledWidth`. Before zooming, saves current playhead position and center time; after, restores scroll to maintain visual continuity.
- **Vertical zoom**: Adjusts `scaledHeight` (pixel-per-octave density)
- **Scroll sync**: Throttled 16ms handler synchronizes X/Y axis containers with the main scrolling container
- **Keyboard**: Arrows shift by 10% of visible range; `[` and `]` shift by 50%

---

## Selection and Multi-Selection

- **Single click**: Selects trajectory via shadow path. Triggers drag dot rendering, recoloring, and TrajSelectPanel update.
- **Shift+drag**: Rubber-band selection box (dashed rectangle). On release, selects all trajectories whose time/frequency ranges overlap the box.
- **Group awareness**: Selecting a grouped trajectory auto-selects all group members.

## TrajSelectPanel (Property Inspector)

When a trajectory is selected, TrajSelectPanel shows:

- **Trajectory type selector**: Grid of archetype icons (filtered by instrument)
- **Pluck toggle** (sitar): Da/Ra stroke selection
- **Dampen toggle** (sitar): Enable/disable palm muting
- **Vowel selector** (vocal): 11 Devanagari vowels
- **Consonant selector** (vocal): 33 Devanagari consonants for start/end positions
- **Vibrato controls**: Periods, extent, initial direction, vertical offset
- **Slope adjustment**: Curvature exponent for sloped bends (IDs 2-5)
- **Octave shift**: Move selected trajectory up/down by octave
- **Phrase division type**: Toggle phrase/section boundary
- **Grouping checkbox**: Create/dissolve trajectory groups for copy-paste
- **Annotation**: Free-text annotations on trajectories and phrases

---

## Polyphonic String-Aware Architecture

For Sitar and Sarangi instruments:

- **Both strings always visible** -- no show/hide toggle; visual differentiation instead
- **Editing targets current string** (`currentStringIdx`), controlled by `ModeSelector` or `J` key
- **String-aware adjacency** for drag constraints and navigation
- **Phrase division nudging** affects both strings, repartitioning string 2 when a boundary moves

## Additional Editor Features

### Control Panels (Expandable from Audio Player Bar)

The editor's bottom bar contains 8 toggle icons, each opening a different control panel:

**1. Display / Spectrogram Controls** (`SpectrogramControls.vue`)
- Colormap selection (36 scientific colormaps via SwatchSelect)
- Intensity power slider (1.0-5.0)
- Sa frequency tuner with audible reference oscillator
- Min/max pitch range (raga-aware pitch selection)
- Color pickers for background, axes, melograph, sargam lines, meter, playhead
- Visibility toggles for all layers (spectrogram, melograph, transcription, sargam lines, bols, phonemes, phrase divs, meter, phrase labels, tala vibhag)
- Per-track: display toggle, sonify toggle, trajectory color picker
- Playhead animation mode (Animated, Block, None, DottedLine)
- Scale system (Sargam, Solfege, Pitch Class, Fixed A440, plus +Cents variants)
- Timing display (Excerpt Time vs Real Time)
- Save/Load/Delete named display setting profiles

**2. Assemblage Editor** (`AssemblageEditor.vue`)
- Create/select/delete assemblages
- Create named strands within assemblages
- `AssemblagePhrasePick` mode: click phrases in the editor to add them
- Move phrases between strands or to "loose"
- Inline strand name editing

**3. Label Editor** (`LabelEditor.vue`)
- Section/Phrase hierarchy toggle
- Structured vs Ad Hoc labeling
- **Section labels**: Top Level (Pre-Chiz Alap, Alap, Composition, Improvisation, Other), Alap sub-type, Composition Type (Dhrupad, Bandish, Thumri, Ghazal, Qawwali, etc.), Section/Tempo (Ati Vilambit through Jhala), Tala assignment
- **Phrase labels**: Phrase Type, Elaboration Type, Articulation Type (instrument-specific), Incidental
- Ad Hoc mode: free-text fields with add/remove
- Double-click to navigate to section/phrase

**4. Meter Controls** (`MeterControls.vue`)
- Tala preset selection (14 standard talas: Tintal, Ektal, Jhaptal, Rupak, etc.)
- Custom mode with configurable hierarchical depth (1-4 layers) and subdivisions
- Tempo slider (20-300 BPM, log scale)
- Cycle repetition count
- Insert Meter at Playhead
- **Pulse Tap Recording**: Start/stop recording, press `=` to tap beats during playback
- Insert Meter from Pulses with Vibhag/Matra level selection
- Attach to Previous Meter (extend with new tapped points)
- Layer visibility slider
- Meter end trimming by Vibhag or Matra anchor

**5. Download** -- Export options (Excel, JSON)

**6. Share** -- Sharing and permissions

**7. Tuning** -- Raga tuning adjustments

**8. Synthesis Controls** (`SynthesisControls.vue`)
- Per-instrument volume controls (Sitar: string gain, chikari gain, dampen cutoff; Sarangi/Vocal: volume)
- Mixed synth gain and recording gain
- Pitch shift slider (-200 to +200 cents)
- Region speed slider (0.5x to 2x, RubberBand time-stretch)
- Metronome toggle with gain slider

### Automation Window

**File:** `src/comps/editor/AutomationWindow.vue`

Pop-up D3-based envelope editor for trajectory volume automation:
- Grey background with 0-1 normalized axes
- Draggable breakpoints
- Shift+click to add, Alt+click to remove
- Handles multi-trajectory automation (compress/partition)

### Annotations
- Free-text tags on trajectories via `TrajectoryAnnotator.vue`
- Stored per-element, displayed in tooltip or inspector

### URL Deep Linking
Query parameters for direct navigation:
- `?t=<seconds>`: Jump to specific time
- `?pIdx=<index>`: Jump to specific phrase
- `?inst=<index>`: Select specific instrument track

### X-Axis Features
- Time ticks in MM:SS or HH:MM:SS
- **Phrase labels row**: Optional "Phrase 1", "Phrase 2", etc.
- **Vibhag labels row**: Tala vibhag symbols (X, 2, O, 3, etc.)
- Click-drag for region selection

### Y-Axis Scale Systems
Sargam, Solfege, Pitch Class, Fixed A440 Pitch + Cents, Sargam + Cents, Solfege + Cents, Pitch Class + Cents, Movable C Pitch + Cents
